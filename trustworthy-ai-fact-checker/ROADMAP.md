# Roadmap

## Phase 0 – Validate (weeks 1–4, no code)
- [ ] Interview 5–10 HR / operations / plant leaders at Louisville-area employers
- [ ] Read *The Great Game of Business*; talk to one ESOP or open-book company
- [ ] Decide the wedge: governance pilot first (recommended) vs. standalone fact-checker
- [ ] Draft a one-page pitch with a concrete pilot offer and price

## Phase 1 – Fact-checker prototype (weeks 2–8)
- [ ] Pipeline: claim extraction → triage → retrieval → verification → critic → report
- [ ] Evaluate on a public labelled dataset (e.g. FEVER sample); record accuracy, calibration, cost/claim
- [ ] Replace assumptions in `docs/03-cost-model.md` with measured numbers
- [ ] Demo: paste a proposal, get a fact-checked brief with sources

## Phase 2 – Pilot (months 3–12)
- [ ] One site / department, one budget slice, one voting cycle
- [ ] Connect the checker to the pilot's internal data (read-only)
- [ ] Human review queue + corrections log
- [ ] Measure outcomes and write the case study

## Phase 3 – Repeat and productize
- [ ] Turn the pilot into a repeatable playbook + software
- [ ] Second and third customers; standalone fact-checker subscription
